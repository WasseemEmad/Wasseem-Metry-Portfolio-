My Projects

Resume to Job Matching System

This system matches a candidate’s resume with live job listings by extracting skills, classifying them, scoring match quality using a language model, and sending notifications for high matches.
This project has two versions one where I use autonomous agents to automate the process of matching resumes with jobs and another where I use a more traditional approach.

🧠 3D Printing Market Lead Analyzer

This AI tool scrapes and analyzes 3D printing articles to identify companies likely to benefit from automation software (like Trinckle 3D). Using GPT-4, it summarizes content, extracts companies, and scores them based on innovation trends such as customization and parametric design.

📈 Amazon Stock Price Prediction & Q&A

This full-stack application forecasts Amazon stock prices using a trained LSTM model and allows users to interact with predictions using natural language. Users can upload CSV/NPY data, visualize trends, and ask questions powered by a LangChain agent with GPT-3.5.

📹 YouTube Video Summarizer & Q&A Assistant

This tool summarizes YouTube videos and answers questions about their content using the video transcript. It combines FastAPI, LangChain agents, and the Hugging Face Mistral-7B model to create a lightweight, LLM-powered video assistant.

💬 Customer Churn Prediction Chatbot

I developed a predictive system that identifies customers likely to churn, then uses an LLM chatbot to discuss the reasons and potential retention strategies. Built for telecom companies, the chatbot merges classical machine learning with LLM-based dialogue.

🖼️ Image Captioning with Deep Learning

I built an end-to-end image captioning system that can describe the content of images using deep learning. The model extracts visual features using a pre-trained CNN (Xception) and generates captions with an LSTM decoder trained on the Flickr8k dataset. The final output mimics how humans describe scenes, making it useful for accessibility tools and media tagging.

🎬 Movie Recommendation System

This system recommends movies to users based on their viewing history and preferences using collaborative filtering and KNN. It features a user-friendly interface built with Streamlit and integrates TMDb and OMDb APIs to display movie posters and metadata. The system is optimized with a sparse matrix representation for fast retrieval.
